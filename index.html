TikTok Shop Collector

เก็บชื่อสินค้า ภาพ ราคา และยอดขายจากหน้ารายการ TikTok Shop ส่งออกเป็น CSV หรือ Excel พร้อมตัวเลือกเลื่อนหน้าและดาวน์โหลดอัตโนมัติ

ดาวน์โหลด ZIP ↓

ติดตั้งผ่าน Developer mode · ข้อมูลเก็บใน Chrome ของคุณ
ภาพใน Excel ใช้สูตร IMAGE และต้องใช้ Excel รุ่นที่รองรับ

วิธีติดตั้งและเริ่มใช้งาน
  1. ดาวน์โหลดและแตกไฟล์ ZIP
  2. เปิด chrome://extensions ใน Chrome แล้วเปิด Developer mode
  3. กด Load unpacked แล้วเลือกโฟลเดอร์ tiktok-shop-collector ที่มีไฟล์ manifest.json
  4. เปิดหน้ารายการสินค้าบน TikTok Shop แล้วเปิดส่วนขยาย
  5. เลือกรูปแบบ CSV หรือ Excel แล้วกด “เก็บสินค้าจากแท็บนี้” โดยเปิดแท็บสินค้าไว้ระหว่างเก็บ

การเก็บข้อมูลขึ้นอยู่กับโครงสร้างหน้า TikTok และสินค้าที่โหลดได้ จึงอาจเก็บได้ไม่ครบ ยังไม่ได้ยืนยันการทำงานบนหน้า TikTok Shop จริงตามเอกสารของรุ่นนี้
