# Suksan Fongfon — เว็บไซต์ส่วนตัว

เว็บสแตติกภาษาไทย รองรับมือถือ เปิด `index.html` ได้ทันที ไม่ต้องติดตั้งแพ็กเกจ

## นำขึ้น GitHub Pages

1. สร้าง repository ในบัญชี GitHub ของคุณ
2. อัปโหลด `index.html` และ `.nojekyll` ไว้ที่โฟลเดอร์หลัก
3. ไปที่ Settings → Pages เลือก Deploy from a branch
4. เลือก branch `main` และโฟลเดอร์ `/ (root)` แล้วบันทึก
5. รอ GitHub แสดงลิงก์เว็บไซต์ในหน้า Pages

ยังไม่ได้เชื่อมต่อหรือเผยแพร่ไปยัง repository ของคุณ ข้อมูลแนะนำตัว ผลงาน และช่องทางติดต่อใช้ข้อความรออัปเดตเพื่อไม่สร้างข้อมูลส่วนตัวขึ้นเอง แก้ข้อความเหล่านี้ใน `index.html` ได้โดยตรง

ฟอนต์ใช้ Google Fonts พร้อมฟอนต์สำรองเมื่อออฟไลน์
